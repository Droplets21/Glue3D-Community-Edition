# Glue3D CE

**Glue3D Comunity Edition** Is the offical way to contribute and keep updates for Glue3D owned and ran by the community
> [!warning]
> Changes have been made to contribution-methods, please read the new rules if you want to contribute

## What does it add?

G3DCE adds many features like importing assets, a compiler system, a more advanced text editor, and many more features which can be toggled from the settings

## How do I get G3DCE?

You can download the latest build from the realeses menu, use tags to filter if you want to use beta or stable builds.
> [!tip]
> use the provided `.sprite3` file to export your base Glue3D projects into G3DCE.

## How do I contribute?

**We have changed the way people contribute to G3DCE**. If you want to contribute to G3DCE via programming, head to the [releases](https://github.com/Droplets21/Glue3D-Community-Edition/releases)\
and download the latest build, then once you've made any changes to the code you want to publish, follow these steps:

1. change the handle of your G3DCE build from `.sb3`, to `.zip`, for example; my `Glue3D_beta_v1.2_.sb3` file would become `Glue3D_beta_v1.2_.zip` (this works with any version)
2. extract and open the zip file (you can extract a zip file by right clicking it and pressing the *extract* option)
3. once you've opened the unzipped folder, make or use your own branch to combine the `project.json` file in the contributions folder, *and* the `project.json` in your unzipped folder
4. then make a pull request to publish the changes!

If you want to simply contribute by giving ideas or feedback, make a simple `.txt` file in the contributions folder with aspects of your idea, or talk about it in the Discord.

## Getting Started

The only thing you need to begin using Glue3D is the `.sb3` file provided in this repository. Head over to the releases on the right and simply download any build by heading over to it's assets, and downloading the `.sb3` file provided.

Now that you have your copy, it's time to read the documentation :).
